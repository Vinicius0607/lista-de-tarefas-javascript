# Lista de Tarefas — JavaScript

Projeto pessoal desenvolvido para praticar fundamentos de desenvolvimento web, JavaScript e Git/GitHub.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Filtrar tarefas por status
- Limpar tarefas concluídas
- Persistir os dados no navegador com `localStorage`
- Layout responsivo para celular e desktop

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Storage API (`localStorage`)
- Git/GitHub

## Como executar

1. Clone este repositório:

```bash
git clone SEU-LINK-DO-REPOSITORIO
```

2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.
